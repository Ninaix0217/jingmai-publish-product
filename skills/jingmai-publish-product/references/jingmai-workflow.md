# 京麦普通发品流程

## 续编已有草稿

1. 在已登录的京麦核对店铺主体。优先使用用户指定的草稿链接或编号，从「商品列表 → 草稿箱」进入对应记录的「编辑」。已打开查看页时，通过草稿箱进入编辑页。只有商品名称时，用品牌和规格核对唯一记录。有多条同名草稿且无法确定目标时，请用户指出是哪一条。
2. 在原草稿上修改用户指定的字段和对应 SKU。涉及批量操作时，先确认应用范围以及会被一并复制的字段。点击「保存草稿」后，重新打开同一草稿，逐行核对修改后的具体值。SKU 属性须打开弹窗核对选项，「已设置几项」可用于定位。用户明确要求提交当前商品时，再按提交条件操作。

## 类目和基本信息

1. 进入「京麦 → 商品 → 发布商品 → 普通发品」。选择实际商品的末级类目，点「下一步，完善其他商品信息」。《发布商品.docx》的类目示例为「个人护理 → 身体护理 → 其它身体护理」。
2. 在「基本信息 → 图片信息识别」导入展开图并点「开始识别」。识别结果用于预填，随后对照展开图复核。
3. 商品标题按「品牌＋产品名称＋产品规格」组成。用户明确指定产品名称时，以该名称为准。若页面单独选择品牌前缀，核对组合后的标题，避免品牌重复。品牌匹配店铺可选项。采购员、销售员和其他类目属性以当前账号分配及实际商品资料为准。
4. 从展开图读取保质期，将天数填入「商品属性 → 展开其他属性 → 保质期」和「物流售后及其他 → 保质期（天）」。若展开图使用年或月，采用用户确认或当前页面明确给出的换算口径。按各商品资料选择属性，分别核对保质期与质保期。

## 规格描述与价格

1. 按实际销售规格建立 SKU。文档流程为单件加三盒装，适用时在原 SKU 之外新增一行。三盒装的「商品名称」使用「原商品名称*3」，「型号」也按单件型号加 `*3`。文档示例中「香型规格」用 `1` 和 `2` 区分两行，第二行对应三盒装。优先使用当前类目的真实规格要求。
2. 打开「SKU属性」并按该商品资料及用户确认的口径填写批准文号或备案编号、产品注册或备案名称及其他适用属性。展开「功效」下拉框，在可输入处键入目标选项全名，例如「其它」，从搜索结果中勾选并确认已显示选中标签。当前列表可能只展示一部分选项，搜索后再判断是否可选。用户明确要求的选项仍搜不到时，报告该项无法填写。表头「批量」会复制整组 SKU 属性，仅当适用行的整组目标值一致时使用，并逐行核对。只改某一项且其他属性有差异时，在对应行分别修改。
3. 以每条 SKU 对应的用户定价为基数，用十进制金额计算并填入同名价格列。

   | 京麦字段 | 公式 |
   | --- | --- |
   | 采购价 | 定价 × 0.9 |
   | 京东价 | 定价 × 1.2 |
   | 市场价 | 定价 × 1.2 × 2 |

   按页面允许的金额精度填写，在写入前保留计算精度。若需要舍入且会影响提交价格，使用页面明确的规则或向用户核实。文档截图的三盒装价格以单件定价的两倍为基数，正文未给出三盒装基数规则。用户只给出一个定价且未说明套装基数时，补问套装定价。
4. 文档里的「包装规格」指包装盒的长、宽、高，填写在 SKU 表的「[包装]长(mm)」「[包装]宽(mm)」「[包装]高(mm)」三列。按用户确认的入仓流程，这三列和「商品毛重(kg)」均先填 `1`，由仓库入仓后调整为实测数据。京麦「物流售后及其他」中另有一个同名数值字段「包装规格」，该发品流程填 `1`。销售单位、商品包装和质保期按该商品确认的选项填写。
5. 将展开图或仓库实物图上的 69 码填入对应 SKU 的「商品条码」。截图只在单件行填写条码。三盒装有独立外包装条码时使用该码，缺少条码且页面允许留空时留空，页面必填时向用户补齐对应条码或经确认的规则。
6. 「商品规格」或「产品规格」指容量和销售组合。SKU 表的「包装清单」填各行商品规格。包装清单和长宽高、毛重是分别填写的必填字段。

## SKU 图片与详情

1. 在「SKU 图片设置」按当前类目的素材要求分别打开「方图」和「透图」选择器。已验证的建模图组合为方图用 JPG、透图用带透明通道的 PNG。原图较大时，等待京麦压缩和上传完成，再按文件名、上传时间和缩略图核对本次素材。自动勾选时核对勾选结果，未自动勾选时手动选择并点「确定」。同一素材适用多条 SKU 时可批量应用，最后逐行检查方图和透图预览。素材不符合当前选择器要求时，按页面提示补齐。
2. 按文档，在「商品详情」中选「代码编辑」，输入字面值 `1`，确认右侧详情预览显示 `1`。用户提供正式详情或页面对该类目另有要求时，按实际内容和页面要求填写。

## 提交与核验

保存草稿后重新进入编辑页，核对包装长宽高、毛重、包装清单和 SKU 属性。若直接填写后字段在重开时回空，改为逐键录入，按 Tab 离开该字段，再保存并复查。

按 Skill 入口的提交条件操作。提交后在审核列表匹配当前商品，核对名称、商品编号和审核状态。文档截图的提交结果显示「待采销审核」，实际回报以当前页面为准。

需要核对本流程的实操结果时，参照 [演示商品示例](product-example.md)。处理其他商品时，按其展开图、用户定价和对应店铺的发品口径取值。
