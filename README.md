# 京麦网页端发品 Skill

在京麦网页端创建新商品或续编已有草稿。支持从包装展开图核对商品信息、按 SKU 定价计算价格、上传建模图，以及按用户要求保存草稿或提交审核。

## 安装

把下面这句话发给支持 Agent Skills 的 Agent。

> 请从 https://github.com/Ninaix0217/jingmai-publish-product/tree/main/skills/jingmai-publish-product 下载并安装京麦发品 Skill。请安装整个目录，包括 `SKILL.md` 和 `references/`。

Codex 可使用内置的 `skill-installer` 从上述 GitHub 目录安装。使用时提供包装展开图、每条 SKU 的定价和方图、透图素材。续编时提供草稿链接或编号及需要修改的字段。
